Écran de détection

Le calcul est fait en Python (NumPy), exécuté dans ton navigateur grâce à Pyodide : le premier chargement télécharge l’interpréteur, ce qui peut prendre quelques secondes. Le modèle résout l’équation de Schrödinger i ∂ψ/∂t = −½ ∇²ψ + V ψ (unités ħ = m = 1) par la méthode « split-step » (FFT) sur une grille de 192 × 192. Le mur est un potentiel très haut, percé d’une ou deux fentes ; les bords du domaine sont absorbants.

L’écran (pointillés cyan) n’intervient pas dans la dynamique : il enregistre le flux de probabilité qui le traverse, intégré sur toute la durée. Cela donne la loi de probabilité d’impact, tracée en rouge. « Tirer les impacts » lance la simulation si besoin, puis tire des électrons indépendants selon cette loi : le motif d’interférences émerge point par point. Les fentes sont supposées infinies selon z, donc cette coordonnée est tirée uniformément sur la vue de face.

La couleur représente √|ψ|² pour garder visibles les zones peu intenses. Modifier un paramètre relance la simulation et efface les impacts.
